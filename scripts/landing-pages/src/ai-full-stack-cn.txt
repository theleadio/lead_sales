p <b>创业者与老板</b>

h2 你最清楚业务怎么运作，项目却常常卡在排不到工程师。课上会带你动手做内部工具、数据仪表板和应用，让产品进度掌握在自己手上。
p <b>营销、设计与运营人员</b>
h2 你知道用户需要什么，也看得出工作流程哪里可以改进。课程会带你用 AI 从设计做到部署，把想法变成客户互动工具或数据追踪表。
p <b>上班族与专业人士</b>
h2 想做实用的 AI 产品，又不打算花几年时间学写代码。课程会提供提示词、工具和工作流程，带你把想法做成一个可以打开的网址。
h2 动手做出来，而不是只听讲
h2 <b>从零开始做</b>
p 第一天，你会从空白页面开始制作仪表板，并接上真实数据库。没有现成模板可以套用，你会先设计画面，再用提示词生成初版，接着在下课前连上 Supabase。课程会留出时间让你亲手操作。
h2 <b>手机版也可以用</b>
p 你会制作适配手机屏幕的应用和内部工具，设定互动逻辑、接入 API，让产品可以实际使用。成果展示时，同学也能直接拿手机试一试。
h2 <b>完成线上部署</b>
p 你会学习使用 React 或 NuxtJS 等框架，把想法做成可以运行的系统；也会接触 API、域名注册、DNS 和 SSL 设置。平时向 IT 申请后可能要等几个月的内部系统，这次可以在周末亲手部署出来。

h2 两天，从第一个作品到正式上线
h1 <b>第一天：巩固基础，做出第一个作品</b>
ul <b><i>AI Agentic Engineering 入门：</i></b><i>了解 Vibe Coding 的基本思路、大语言模型（LLM）能做什么，以及如何选择合适的工具。</i>‖<i>实战制作仪表板：制作一个连接数据库、能适应不同屏幕的仪表板，例如销售追踪表。</i>‖<i>UI / UX 与数据库基础：用 AI 工具调整界面设计，学习 SQL，并把 Supabase 接成后台数据库。</i>‖<i>内部小工具：开发处理特定任务的小工具，并制作一个供营销团队使用的客户互动工具。</i>‖<i>手机版应用：用 Vibe Coding 以手机优先的方式开发应用，例如面向客户的询问表单。</i>‖<i>互动小产品：为产品加入互动逻辑和游戏化机制。</i>
img M/6a36bea70a683b64fe2d9153.png
h1 <b>第二天：把作品部署上线</b>
ul <b><i>认识开发框架：学习如何用 Vibe Coding 运用 NextJS、ReactJS 等生产级框架。</i></b>‖<b><i>API、域名与正式上线：创建并测试 API，注册域名、设置 DNS 和 SSL，再把系统部署到正式环境。</i></b>‖<b><i>进阶网格布局：学习 CSS Grid 和复杂内容版面的处理方式，并升级第一天做出的作品。</i></b>‖<b><i>示范与教练指导：学习进阶内容，包括生成式视觉效果，以及 Three.js 3D 入门。</i></b>‖<b><i>Hyperframe 界面：把多个系统整合到同一个界面中。</i></b>‖<b><i>成果展示：展示已经部署的系统，听取同学反馈和讲师点评。</i></b>
